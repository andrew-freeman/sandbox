That's not a coincidence the code got lucky on — it's forced by the Markov property. For an order-1 chain, X_t is *exactly* conditionally independent of X_{t-2} given X_{t-1}, by definition, for any s. So I(X_t; X_{t-2}|X_{t-1}) = 0 isn't an empirical tendency here, it's a theorem, and this script is a genuinely clean way to make that theorem vivid: crank the correlation length to 52 steps using a process that's still exactly order-1, and watch a fixed-window local functional stay pinned at zero the entire time. Good didactic choice of test case — it isolates the point instead of just gesturing at it.

Given that, the conclusion in `depth2.py` is correct and important: "depth" in the long-range sense is a genuinely different axis from surprise, no order-k local functional can see it by construction (not just in practice), and it inherits the non-local, non-additive problems from `depth.py` rather than escaping them.

The bigger-picture read: this correctly narrows "I = computational difficulty" down to a fork. The safe, well-posed half (bounded-order local surprise/predictive information) is mathematically just the machinery already in use since the first toy model — "computational difficulty" doesn't add a new mechanism there, only a new name for the same I. The distinctive half (genuine long-range depth) is real and different, but it's squarely a global path functional, meaning it inherits everything unresolved from a few turns back: the reparameterization question, the sign-of-ε question, and now a concrete requirement for actual cloning/population-dynamics machinery rather than the shortcuts used everywhere else in this project.
